# Security policy

## Supported versions

Security fixes are provided for the latest stable release.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by emailing **omaralwi2010@gmail.com** with the subject `Laravel Forge Deployments security report`.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Do not include real API tokens, deployment hook URLs, server credentials, or sensitive deployment output. Please allow time to investigate before public disclosure.
